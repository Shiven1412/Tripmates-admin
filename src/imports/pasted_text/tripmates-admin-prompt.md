# Figma Make Prompt – TripMates Admin Platform

## Project Overview

Create a complete multi-page enterprise-grade admin platform for **TripMates**.

### Platform Purpose

TripMates Admin is the central control center for managing:

- Travelers
- Service Providers
- Trips
- Travel Dates
- Bookings
- Payments
- Reviews
- Marketplace
- Support Tickets
- Safety & Moderation
- Analytics
- AI Monitoring
- Fraud Detection

This should feel like a modern SaaS back-office platform used by operations teams, moderators, support agents, finance teams, and super admins.
